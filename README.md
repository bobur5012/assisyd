# Yo'ldosh — голосовой ассистент для BYD

Приложение для магнитол BYD (DiLink, Android): главный экран с 3D-машиной, плеер для Яндекс Музыки,
быстрые маршруты в Яндекс Навигаторе и голосовой ассистент на узбекском и русском, который работает без интернета.

## Скачать

Последняя сборка: **https://github.com/bobur5012/assisyd/releases/latest/download/yoldosh.apk**

Каждый пуш в `main` автоматически собирает новый APK (GitHub Actions → Releases).

## Что умеет версия 0.1

- Первый запуск: по шагам просит разрешения (микрофон, геолокация, поверх приложений, уведомления, спецвозможности, фон, автозапуск).
- Голос (офлайн, Vosk): «Salom Yo'ldosh, musiqa qo'y», «Поехали домой», «Найди зарядку», «Громче», «Открой YouTube», «Который час».
- Аватар ассистента говорит, пока звучит ответ.
- Плеер показывает трек и обложку из Яндекс Музыки и управляет ей.
- Маршруты открываются в Яндекс Навигаторе (или Картах).
- Плавающая кнопка ассистента поверх других приложений; вызов кнопкой на руле (через спецвозможности).

Управление машиной (окна, багажник, климат) — в следующей версии, после проверки на конкретной прошивке.

## Устройство

- `app/src/main/java/uz/yoldosh/app/` — Kotlin: мост к интерфейсу, распознавание речи, озвучка, медиа, разрешения, сервисы.
- `app/src/main/assets/web/` — интерфейс (HTML/CSS/JS), `commands.js` — понимание команд.
- Голосовые модели скачиваются при сборке (см. `.github/workflows/build.yml`).
